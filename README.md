# 🛠️ Сервисный Дашборд — Учет Рабочего Времени & Голосовой ИИ

Полноценное одностраничное веб-приложение (SPA) для автоматического учета отработанных часов, распределения по категориям работ и заказам с реактивной облачной синхронизацией Firebase Firestore, поддержкой голосового ИИ-помощника и ролями **"Мастер"** и **"Начальник (Только чтение)"**.

## 🌟 Ключевые возможности

1. **🎙️ Голосовой ИИ-Помощник ("Диктовка смены")**:
   - Плавающая кнопка **FAB** в правом нижнем углу экрана с пульсирующим индикатором записи.
   - Однократная загрузка локальной нейросети в кэш браузера (~1.2 ГБ) с удобным прогресс-баром (0–100%).
   - Нативное распознавание речи через Web Speech API на языках **PL / RU / EN**.
   - **Умный NLU-парсер сущностей**: автоматическое извлечение номера заказа, оборудования, количества часов и категории работ (`H` — Гидравлика, `P` — Пневматика, `E` — Электрика, `S` — Слесарка, `D+N` — Диагностика/Ремонт).
   - Интерактивное модальное окно проверки предзаполненных данных перед сохранением.

2. **🔐 Разделение прав доступа и Белый список (`ALLOWED_MASTERS`)**:
   - 🔒 **Режим Начальника ("Только чтение")**: Доступен без авторизации. Отображает полную статистику, сводную аналитическую таблицу (Pivot) и журнал. Форма добавления, кнопки удаления и ИИ-кнопка скрыты.
   - 🛠️ **Режим Мастера (Авторизован)**: Доступно создание смен, удаление записей и голосовой ИИ.
   - 🛡️ **Белый список `ALLOWED_MASTERS`**: Возможность ограничить права редактирования конкретными Email адресами мастеров.

3. **🌍 Мультиязычность (i18n: PL / RU / EN)**:
   - Мгновенное переключение всего интерфейса на польский, русский или английский язык с сохранением выбора в `localStorage`.

4. **⚡ Облачный синхрон в реальном времени**:
   - Данные мгновенно синхронизируются между смартфонами и ПК через Firebase Firestore SDK v11.

5. **🛡️ Безопасность секретов (.env & Netlify Auto-build)**:
   - Все ключи Firebase и списки мастеров вынесены из исходного кода в `.env` и `env.js` (исключены из Git через `.gitignore`).
   - Настроен скрипт автосборки `build-env.js` + `netlify.toml` для корректного деплоя на Netlify.

## 📋 Структура файлов проекта

- `index.html` — Главное веб-приложение SPA (Tailwind CSS + Vanilla JS + Firebase SDK v11 + Voice AI).
- `.env` — Файл локальных секретов (API ключи Firebase, `ALLOWED_MASTERS`). Игнорируется Git.
- `env.js` — Локальный конфигурационный скрипт, подключаемый в `index.html`. Игнорируется Git.
- `env.example.js` — Публичный безопасный шаблон конфигурации для разработчиков.
- `build-env.js` — Скрипт генерации `env.js` при автоматической сборке на Netlify.
- `netlify.toml` — Файл конфигурации сборки Netlify.
- `firestore.rules` — Правила доступа к облачной базе данных Firestore.
- `.gitignore` — Список исключений для Git (блокировка секретов и логов).
- `README.md` — Актуальное руководство по проекту.

## 🚀 Пошаговая инструкция по локальному запуску

### 1. Настройка конфигурации
1. Скопируйте файл `env.example.js` в `env.js`:
   ```bash
   cp env.example.js env.js
   ```
2. Откройте `env.js` (или создайте `.env`) и впишите ключи вашей базы Firebase `vhs-zps`:
   ```javascript
   window.ENV = {
     FIREBASE_API_KEY: "AIzaSy...",
     FIREBASE_AUTH_DOMAIN: "vhs-zps.firebaseapp.com",
     FIREBASE_PROJECT_ID: "vhs-zps",
     FIREBASE_STORAGE_BUCKET: "vhs-zps.firebasestorage.app",
     FIREBASE_MESSAGING_SENDER_ID: "122824920296",
     FIREBASE_APP_ID: "1:122824920296:web:...",
     FIREBASE_MEASUREMENT_ID: "G-...",
     ALLOWED_MASTERS: ["vlad@example.com"]
   };
   ```

### 2. Локальный запуск
Откройте файл `index.html` в браузере или запустите локальный сервер:
```bash
npx http-server . -p 8085
```

Перейдите по адресу: `http://localhost:8085/`
