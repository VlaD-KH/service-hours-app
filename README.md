# 🛠️ Сервисный Дашборд — Учет Рабочего Времени

Полноценное одностраничное веб-приложение (SPA) для автоматического учета отработанных часов, распределения по категориям работ и заказам с реактивной облачной синхронизацией Firebase Firestore и поддержкой ролей **"Мастер"** и **"Начальник (Только чтение)"**.

---

## 🌟 Ключевые возможности

1. **Разделение прав доступа (Авторизация)**:
   - 🔒 **Режим Начальника ("Только чтение")**: Без авторизации отображается полный дашборд, статистика, сводная таблица по заказам и журнал записей. Форма добавления и иконки удаления скрыты.
   - 🛠️ **Режим Мастера (Авторизован)**: Доступен функционал создания новых смен, автоподстановки номеров заказов и оборудования, а также удаления записей.
2. **Облачный синхрон в реальном времени**: Данные мгновенно синхронизируются между смартфонами и ПК через Firebase Firestore SDK v11.
3. **Автоматическая аналитика (Pivot Table)**: Авторасчет суммы часов по объектам в разрезе категорий:
   - `H` — Гидравлика
   - `P` — Пневматика
   - `E` — Электрика
   - `S` — Слесарные работы
   - `D+N` — Диагностика и Ремонт
4. **Фильтрация и История**: Быстрый выбор любого месяца и года с перерасчетом статистики.

## 🚀 Пошаговая инструкция по настройке Firebase (Для Новичка)

### Шаг 1: Создание проекта в Firebase
1. Перейдите в [Firebase Console](https://console.firebase.google.com/) и войдите под аккаунтом Google.
2. Нажмите **"Добавить проект"** (Add project).
3. Введите название проекта (например, `service-hours-app`) и нажмите **"Продолжить"**.
4. Отключите Google Analytics (для простоты) и нажмите **"Создать проект"**.

---

### Шаг 2: Включение базы данных Firestore Database
1. В левом меню выберите **"Build"** -> **"Firestore Database"**.
2. Нажмите **"Создать базу данных"** (Create database).
3. Выберите регион (например, `eur3 (europe-west)` или ближайший к вам).
4. На шаге "Правила защиты" выберите **"Начать в тестовом режиме"** (Start in test mode) и нажмите **"Включить"**.
5. Перейдите во вкладку **"Правила"** (Rules) вверху экрана Firestore и вставьте следующие правила:

```javascript
rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {
    match /work_entries/{entryId} {
      // Чтение разрешено всем (Начальнику)
      allow read: if true;
      // Запись и удаление — только авторизованному мастеру
      allow create, update, delete: if request.auth != null;
    }
  }
}
```
6. Нажмите кнопку **"Опубликовать"** (Publish).

---

### Шаг 3: Включение Авторизации (Authentication)
1. В левом меню выберите **"Build"** -> **"Authentication"**.
2. Нажмите **"Начать"** (Get started).
3. Во вкладке **"Способы входа"** (Sign-in method):
   - Выберите **Email/Пароль** (Email/Password) -> Включите первый тумблер -> Нажмите **"Сохранить"**.
   - *(Опционально)* Выберите **Google** -> Включите тумблер -> Укажите поддерживаемый Email -> Нажмите **"Сохранить"**.
4. Перейдите во вкладку **"Users"** (Пользователи) и нажмите **"Добавить пользователя"** (Add user).
5. Введите ваш Email и надежный пароль (под этими данными вы будете входить в приложение как Мастер).

---

### Шаг 4: Получение `firebaseConfig` и вставка в `index.html`
1. Нажмите на иконку шестеренки **⚙️ (Настройки проекта)** в левом верхнем углу меню -> **"Общие"** (General).
2. Прокрутите вниз до блока "Ваши приложения" и нажмите на иконку веб-сайта **`</>`**.
3. Зарегистрируйте приложение (введите любое имя, например `Service Dashboard Web`).
4. Скопируйте объект `firebaseConfig`, который будет выглядеть так:

```javascript
const firebaseConfig = {
  apiKey: "AIzaSyD...",
  authDomain: "your-app.firebaseapp.com",
  projectId: "your-app",
  storageBucket: "your-app.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abcdef..."
};
```

5. Откройте файл `index.html` и замените шаблонный `firebaseConfig` (строки ~195-202) на скопированный из консоли Firebase.

## 🌐 Бесплатное размещение в Интернете (Деплой)

Вы можете опубликовать файл `index.html` бесплатно за 1 минуту одним из следующих способов:

### Вариант А: Vercel (Самый простой способ)
1. Зарегистрируйтесь на [Vercel.com](https://vercel.com).
2. Установите Vercel CLI или перетащите папку с проектом напрямую в интерфейс Vercel Dashboard.
3. Либо через терминал:
   ```bash
   npx vercel
   ```
4. Вы получите готовую публичную ссылку вида `https://service-hours-app.vercel.app`, которую можно отправить начальнику.

---

### Вариант Б: Netlify Drop (За 30 секунд без Git)
1. Перейдите на страницу [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащите папку с файлом `index.html` в окно браузера.
3. Netlify мгновенно сгенерирует публичную ссылку на ваш сайт.

---

### Вариант В: GitHub Pages
1. Создайте публичный репозиторий на [GitHub.com](https://github.com).
2. Загрузите файл `index.html`.
3. Перейдите в **Settings** -> **Pages** -> Выберите ветку `main` (или `master`) -> Нажмите **Save**.
4. Через 1 минуту ваш дашборд будет доступен по адресу `https://ваш-логин.github.io/название-репозитория/`.
