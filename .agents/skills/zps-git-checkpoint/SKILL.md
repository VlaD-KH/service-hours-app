# ZPS Git Checkpoint & Backup Skill

## Overview
Данный skill гарантирует непрерывную сохранность рабочих версий проекта "Сервисные Часы ZPS", предотвращает потерю кода и автоматизирует создание резервных контрольных веток.

## Workflow

### 1. Фиксация изменений в локальном Git
- Создать понятный коммит с описанием внесённых изменений.
- Создать резервную боковую ветку восстановления `backup/checkpoint-<name>`.

### 2. Запись в antigravity_debug.log
- Добавить строчку с меткой времени, хешем коммита и описанием выполненного этапа в файл `antigravity_debug.log`.

### 3. Безопасный Push в Remote
- Выполнить отправку коммита в главную ветку `main` и резервную боковую ветку:
  ```bash
  git push origin main && git push origin backup/checkpoint-<name>
  ```
